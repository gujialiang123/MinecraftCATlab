# Client

Connect with **Minecraft: Java Edition 26.3** using a fresh vanilla installation. The active server does not require a modpack, NeoForge, FTB Ultimine, or FTB Library.

1. In the official Minecraft Launcher, select Java Edition 26.3. In Prism Launcher, create a new Minecraft 26.3 instance with no mod loader and select Java 25 if Java is managed manually.
2. Sign in with a legitimate Microsoft/Minecraft account and launch the game.
3. Open **Multiplayer → Add Server** and enter `98.93.3.136:25565`.

The server runs survival on easy difficulty with a four-player maximum. A bonus chest is generated near the fresh world's initial spawn. Owner-approved operators have permission to use server commands; other players have ordinary survival permissions. Command blocks and RCON are disabled. Online account authentication is enabled; the whitelist is disabled and no server password is needed. Tailscale members may connect to `100.112.93.136:25565` instead.

The old `JialiangCraft-1.1.0.mrpack` and its manual FTB additions belong to the archived NeoForge 1.21.1 server. Keep that instance separate if you want to retain it. The active vanilla setup does not publish or need a replacement `.mrpack`. Simple Voice Chat is no longer part of the active server.
