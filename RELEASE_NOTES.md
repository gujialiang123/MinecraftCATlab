# JialiangCraft 1.1.0

Minecraft 1.21.1 · NeoForge 21.1.252 · 26 mods in the GitHub base pack, plus 2 required manual FTB mods

This update adds AppleSkin, Corpse, Nature's Compass, and Explorer's Compass, plus their Architectury API dependency, to the GitHub base pack. The server also runs FTB Ultimine and FTB Library. These two FTB mods are **not included** in the downloadable `.mrpack` and must be added manually before joining.

1. Import `JialiangCraft-1.1.0.mrpack` into Prism Launcher.
2. Download the exact NeoForge 1.21.1 files [FTB Ultimine 2101.1.15](https://www.curseforge.com/minecraft/mc-mods/ftb-ultimine-forge/files/8231400) and [FTB Library 2101.1.37](https://www.curseforge.com/minecraft/mc-mods/ftb-library-forge/files/9008089) from CurseForge, then add both JARs to the instance's **Mods** tab.
3. Use Java 21, sign in with a legitimate Minecraft account, and join the preconfigured server at `98.93.3.136:25565`.

There is no server password or whitelist. Simple Voice Chat's UDP port is not forwarded publicly, so voice chat is unavailable through the VPS relay.
